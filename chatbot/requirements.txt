
EOS Chatbot — Requirements
==========================

This is a Node.js / TypeScript project, not Python — there is nothing here
for `pip install`. Actual dependency resolution happens via `package.json`
+ `package-lock.json` and `npm install`; this file is a plain-text summary
of what's needed to run it, for anyone (or any checklist) expecting a
requirements.txt.

1. Runtime
----------
- Node.js  v20+ (developed/tested on v24.11.1)
- npm      (ships with Node)
- No Python, no GPU required.
- No external AI *API* — but there IS a local AI *service* dependency now,
  see section 2. The intent classifier itself (SBERT via
  @xenova/transformers) still runs fully offline in-process as an ONNX
  model, with no service to install for that part.

2. External services
---------------------
- PostgreSQL — the SAME database EOS-backend already uses (Supabase or
  local copy). This app only ever runs read queries against it; it never
  runs migrations. Exceptions: 5 chatbot-owned tables it DOES write to —
  query_logs, training_examples, model_performance (the learning/analytics
  pipeline) and chat_conversations, chat_messages (per-user chat history /
  "Recents" sidebar, see README.md "Chat history") — must exist in that
  same database (plain CREATE TABLE, no migration framework used; see
  scripts/create-chat-history-tables.ts and git history for the DDL if
  they're missing).

- Ollama (NEW — a real, separate local system service, not optional
  boilerplate) — https://ollama.com. Used for two things, both of which
  degrade gracefully (silently skipped, never a crash) if Ollama isn't
  running:
    * LLM-based intent reranking (only for low-confidence SBERT calls)
    * Rewording an already-correct reply for more natural phrasing
  Setup:
    ollama pull llama3.2:3b
  Default endpoint: http://localhost:11434 (override via OLLAMA_HOST).
  Model name is configurable via OLLAMA_MODEL, default llama3.2:3b.
  Needs internet ONCE to pull the model (~2GB download); fully offline
  after that.

- SBERT model weights (Xenova/paraphrase-multilingual-MiniLM-L12-v2,
  ~118MB quantized ONNX). Normally auto-cached under .transformers-cache/
  on first run. NOTE: this specific model's weights are OVER GitHub's
  100MB per-file limit, so they are NOT committed to this repo (unlike the
  originally-committed, smaller all-MiniLM-L6-v2 model) — expect ONE
  internet-connected first run to download from the Hugging Face hub, then
  fully offline after that. If your network blocks the HF hub outright,
  copy a pre-downloaded .transformers-cache/Xenova/paraphrase-multilingual-MiniLM-L12-v2/
  folder from another machine, or use Git LFS.

4. Environment variables (copy .env.example to .env and fill in)
------------------------------------------------------------------
  PORT                          — server port (default 4000)
  NODE_ENV                      — development | production
  DATABASE_URL                  — MUST be the exact same value as
                                   EOS-backend/.env's DATABASE_URL (same DB).
                                   Prefer the transaction-mode pooler port
                                   (:6543) over session-mode (:5432) — see
                                   README.md for why.
  CHATBOT_JWT_SECRET            — any long random string; independent of the
                                   backend's own JWT_SECRET (temporary
                                   standalone-testing auth — see
                                   src/auth/README.md)
  CHATBOT_JWT_EXPIRES_IN        — e.g. "8h"
  INTENT_CONFIDENCE_THRESHOLD   — 0-1, default 0.55. Minimum cosine score
                                   to accept a classification.
  INTENT_AMBIGUITY_MARGIN       — 0-1, default 0 (disabled — measured to
                                   REDUCE real accuracy, see env.ts).
  INTENT_LLM_RERANK_ENABLED     — true|false, default true. Toggles the
                                   Ollama reranker.
  INTENT_LLM_RERANK_CEILING     — 0-1, default 0.72. Reranker only runs
                                   when SBERT's own confidence is below this.
  INTENT_LLM_RERANK_TOP_K       — integer, default 4. Candidates handed to
                                   the reranker.
  REPLY_PARAPHRASE_ENABLED      — true|false, default true. Toggles Ollama
                                   reply rewording.
  OLLAMA_HOST                   — default http://localhost:11434
  OLLAMA_MODEL                  — default llama3.2:3b
  ALLOWED_ORIGINS               — comma-separated CORS allow-list

5. One-time setup, in order
-----------------------------
  npm install
  cp .env.example .env          # then edit .env, see section 4
  npm run prisma:generate       # generates the Prisma client
  npm run train                 # parses the training dataset .docx (must
                                 # sit one directory above this folder) and
                                 # builds SBERT embeddings — downloads the
                                 # model weights on first run (~118MB)
  ollama pull llama3.2:3b       # optional but recommended — enables
                                 # reranking + reply paraphrasing; app runs
                                 # fine without it, just less polished
  npm run dev                   # starts the dev server on $PORT
